# رها VPN (Raha VPN)

اپلیکیشن اندروید با رابط کاربری فارسی و تم تیره.

## وضعیت فعلی
- پوسته اولیه Android با Jetpack Compose
- رابط فارسی و تم سرمه‌ای/طلایی
- فهرست سرورها و افزودن لینک کانفیگ‌های VMess، VLESS، Trojan، Shadowsocks و WireGuard
- ذخیره‌سازی لینک‌های کانفیگ با رمزگذاری AES-GCM و کلید Android Keystore
- بررسی دسترسی DNS-over-HTTPS از طریق Cloudflare و Google
- گردش ساخت خودکار APK آزمایشی با GitHub Actions

## ساخت پروژه
پروژه را با Android Studio سازگار با Android Gradle Plugin 8.7.3 باز کنید و Gradle Sync را اجرا کنید.

## نکته مهم
در این نسخه هنوز موتور تونل VPN پیاده‌سازی نشده است؛ دکمه اتصال عمداً غیرفعال است و افزودن کانفیگ به معنی برقرار شدن اتصال نیست. بررسی DNS فقط دسترسی DNS را آزمایش می‌کند و جایگزین VPN نیست. جستجوی منابع عمومی کانفیگ و موتور اتصال در مراحل بعدی اضافه خواهند شد.

## ساخت خودکار
با هر push به شاخه main، گردش GitHub Actions پروژه را می‌سازد و APK آزمایشی را به‌صورت Artifact به مدت ۱۴ روز نگه می‌دارد.
