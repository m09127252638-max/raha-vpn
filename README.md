# H.MAGHSODI

اپلیکیشن اندروید H.MAGHSODI با رابط کاربری فارسی و تم تیره.

## وضعیت فعلی
- پوسته اولیه Android با Jetpack Compose
- رابط فارسی و تم سرمه‌ای/طلایی
- فهرست سرورها و افزودن لینک کانفیگ
- ذخیره‌سازی لینک‌های کانفیگ با رمزگذاری AES-GCM و کلید Android Keystore
- بررسی دسترسی DNS-over-HTTPS از طریق Cloudflare و Google
- دریافت فهرست لینک‌های عمومی V2Ray از چند مخزن عمومی GitHub و امکان افزودن دستی هر مورد به فهرست رمزگذاری‌شده
- مبدل اولیه لینک‌های VLESS و Trojan به ساختار پیکربندی sing-box (هنوز به سرویس تونل متصل نشده است).

## وضعیت اتصال
در این نسخه هنوز تونل VPN فعال نشده است؛ دکمه اتصال تا تکمیل سرویس Android VPN، پیاده‌سازی PlatformInterface و آزمایش چرخه اتصال/قطع غیرفعال می‌ماند. مبدل فعلی فقط مرحله تبدیل لینک را آماده می‌کند و به معنی قابل‌اتصال بودن سرور نیست. لینک‌های دیگر ممکن است ذخیره شوند، اما پشتیبانی اجرایی آن‌ها هنوز تکمیل نشده است. جستجوی عمومی فقط لینک‌ها را از منابع ثالث دریافت و نمایش می‌دهد؛ آنلاین بودن، امنیت یا قابل‌اتصال بودن آن‌ها تضمین نمی‌شود و کاربر باید مورد دلخواه را دستی اضافه کند. بررسی DNS فقط دسترسی DNS را آزمایش می‌کند و جایگزین VPN نیست.

## ساخت پروژه
پروژه را با Android Studio سازگار با Android Gradle Plugin 8.7.3 باز کنید و Gradle Sync را اجرا کنید.
