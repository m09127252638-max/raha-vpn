# H.MAGHSODI

اپلیکیشن اندروید H.MAGHSODI با رابط کاربری فارسی و تم تیره.

## وضعیت فعلی
- پوسته اولیه Android با Jetpack Compose
- رابط فارسی و تم سرمه‌ای/طلایی
- فهرست سرورها و افزودن لینک کانفیگ
- ذخیره‌سازی لینک‌های کانفیگ با رمزگذاری AES-GCM و کلید Android Keystore
- بررسی دسترسی DNS-over-HTTPS از طریق Cloudflare و Google
- دریافت فهرست لینک‌های عمومی V2Ray و پل‌های obfs4 از منابع ثالث GitHub و امکان افزودن دستی آن‌ها به فهرست رمزگذاری‌شده
- اعتبارسنجی و ذخیره امن خط کامل پل obfs4 (نشانی، fingerprint، cert و iat-mode)
- موتور Tor Android به‌همراه IPtProxy برای اجرای پل‌های obfs4
- راه‌اندازی Tor از روی خط کامل پل obfs4 و ارائه پروکسی محلی SOCKS5 روی 127.0.0.1:19050
- اعتبارسنجی و ذخیره رمزگذاری‌شده پل‌های obfs4 (IPv4 و IPv6)

## وضعیت یکپارچه‌سازی موتور VPN
کتابخانه‌های IPtProxy و sing-box/libbox هر دو با gomobile ساخته شده‌اند و هرکدام کلاس‌ها و runtime جاوایی `go.Seq` را همراه خود می‌آورند. افزودن دو AAR مستقل باعث خطای قطعی `Duplicate class go.Seq` در ساخت اندروید می‌شود؛ این مشکل با `pickFirst` یا حذف سادهٔ کلاس‌ها حل نمی‌شود. طبق راهکار مستند پروژهٔ Go، این دو بخش باید در یک AAR واحد با یک runtime مشترک ساخته شوند، یا مسیر اجرای obfs4 بدون AAR دوم بازطراحی شود. تا زمان آماده‌شدن این بستهٔ یکپارچه، وابستگی libbox عمداً به پروژهٔ اصلی اضافه نشده تا نسخهٔ فعلی قابل ساخت باقی بماند. سرویس VPN و اتصال واقعی هنوز پیاده‌سازی/تأیید نشده‌اند.

## وضعیت اتصال
در این نسخه هنوز تونل VPN فعال نشده است؛ دکمه اتصال تا تکمیل سرویس Android VPN، پیاده‌سازی PlatformInterface و آزمایش چرخه اتصال/قطع غیرفعال می‌ماند. مبدل فعلی فقط مرحله تبدیل لینک را آماده می‌کند و به معنی قابل‌اتصال بودن سرور نیست. لینک‌های دیگر ممکن است ذخیره شوند، اما پشتیبانی اجرایی آن‌ها هنوز تکمیل نشده است. جستجوی عمومی لینک‌های V2Ray و فهرست‌های پل obfs4 را از منابع ثالث دریافت و نمایش می‌دهد؛ آنلاین بودن، امنیت یا قابل‌اتصال بودن آن‌ها تضمین نمی‌شود و کاربر باید مورد دلخواه را دستی اضافه کند. پل‌های obfs4 متعلق به Tor هستند و sing-box آن‌ها را اجرا نمی‌کند؛ برای اتصال به آن‌ها باید Tor و obfs4proxy (یا پیاده‌سازی سازگار) جداگانه در برنامه ادغام شود. در این نسخه obfs4 فقط قابل جستجو، واردکردن و ذخیره‌سازی است. بررسی DNS فقط دسترسی DNS را آزمایش می‌کند و جایگزین VPN نیست.

## ساخت پروژه
پروژه را با Android Studio سازگار با Android Gradle Plugin 8.7.3 باز کنید و Gradle Sync را اجرا کنید.
