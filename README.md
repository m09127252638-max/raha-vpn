# H.MAGHSODI

اپلیکیشن اندروید H.MAGHSODI با رابط فارسی و تم تیره.

## امکانات موجود
- رابط کاربری فارسی با تم سرمه‌ای و طلایی
- افزودن، انتخاب و حذف لینک‌های سرور
- رمزگذاری لینک‌های ذخیره‌شده با AES-GCM و Android Keystore
- بررسی دسترسی DNS-over-HTTPS
- دریافت فهرست کانفیگ‌های عمومی و پل‌های obfs4 از منابع ثالث
- راه‌اندازی Tor و obfs4proxy از طریق IPtProxy و ارائه SOCKS5 محلی روی `127.0.0.1:19050`

## وضعیت واقعی اتصال
**این نسخه هنوز VPN سراسری اندروید نیست.** اجرای Tor/obfs4 فقط یک پروکسی SOCKS5 محلی ایجاد می‌کند و به‌تنهایی ترافیک سایر برنامه‌های گوشی را از تونل عبور نمی‌دهد.

همچنین موتور Xray در APK فعلی بسته‌بندی نشده و کانفیگ‌های VLESS، VMess، Trojan و سایر پروتکل‌ها فعلاً فقط قابل ذخیره‌سازی/نمایش هستند؛ ساخت فایل کانفیگ به معنی اتصال عملی نیست.

برای تبدیل برنامه به VPN واقعی باید موتور سازگار با Android TUN (مانند libbox/sing-box)، سرویس Android `VpnService`، پیاده‌سازی `PlatformInterface`، چرخه مجوز/اعلان foreground و مدیریت قطع و وصل شبکه یکپارچه و روی دستگاه آزمایش شوند. obfs4 متعلق به Tor است و باید از مسیر جداگانه Tor به موتور TUN متصل شود؛ sing-box به‌تنهایی پل obfs4 را اجرا نمی‌کند.

کانفیگ‌ها و پل‌های عمومی از منابع ثالث دریافت می‌شوند؛ آنلاین بودن، امنیت یا قابل‌اتصال بودن آن‌ها تضمین‌شده نیست. اطلاعات محرمانه کانفیگ‌ها را با دیگران به اشتراک نگذارید.

## ساخت
پروژه با Android Gradle Plugin 8.7.3 و JDK 17 تنظیم شده است. گردش‌کار GitHub Actions تست‌های واحد و APK آزمایشی arm64 را می‌سازد.
