# رها VPN (Raha VPN)

اپلیکیشن اندروید با رابط کاربری فارسی و تم تیره.

## وضعیت فعلی
- پوسته اولیه Android با Jetpack Compose
- رابط فارسی و تم سرمه‌ای/طلایی
- فهرست سرورها و افزودن لینک کانفیگ‌های VMess، VLESS، Trojan، Shadowsocks و WireGuard
- بخش جستجوی منابع عمومی در حال آماده‌سازی

## ساخت پروژه
پروژه را با Android Studio سازگار با Android Gradle Plugin 8.7.3 باز کنید و Gradle Sync را اجرا کنید.

## نکته مهم
در این نسخه هنوز موتور تونل VPN پیاده‌سازی نشده است؛ دکمه اتصال عمداً غیرفعال است و افزودن کانفیگ به معنی برقرار شدن اتصال نیست. موتور VPN، اعتبارسنجی امن منابع و جستجوی آنلاین در مراحل بعدی اضافه خواهند شد.
