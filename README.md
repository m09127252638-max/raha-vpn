# H.MAGHSODI

اپلیکیشن اندروید H.MAGHSODI با رابط فارسی و تم تیره.

## امکانات پیاده‌سازی‌شده در شاخه فعلی
- رابط کاربری فارسی با تم سرمه‌ای و طلایی
- افزودن، انتخاب و حذف لینک‌های سرور
- رمزگذاری لینک‌های ذخیره‌شده با AES-GCM و Android Keystore
- بررسی DNS-over-HTTPS و جستجوی منابع عمومی کانفیگ و پل obfs4
- سرویس Android `VpnService` و ایجاد رابط TUN برای مسیریابی ترافیک دستگاه
- موتور بومی libXray با تبدیل لینک‌های VLESS و Trojan (TCP، WebSocket و gRPC با محدودیت‌های مشخص)؛ VMess فعلاً در مسیر اتصال پشتیبانی نمی‌شود
- محافظت از سوکت‌های خروجی موتور با `VpnService.protect()`
- مسیر جداگانه Tor/obfs4 با IPtProxy و SOCKS محلی؛ UDP در این حالت مسدود می‌شود تا از نشت ترافیک جلوگیری شود
- ساخت خودکار AAR موتور ترکیبی Xray و obfs4 و APK آزمایشی arm64 در GitHub Actions

## وضعیت اعتبارسنجی
ساخت موتور بومی، تست‌های واحد و ساخت APK آزمایشی arm64 در CI با موفقیت انجام شده‌اند.

**اتصال واقعی روی گوشی Android هنوز به‌صورت عملی تأیید نشده است.** موفقیت کامپایل و تست‌های واحد به‌تنهایی تضمین نمی‌کند که هر کانفیگ عمومی یا پل obfs4 در شبکه واقعی متصل شود. پیش از انتشار باید روی دستگاه واقعی، اتصال و قطع، DNS، IPv4/IPv6، محافظت سوکت‌ها، بازیابی پس از تغییر/قطع شبکه و مسیر obfs4 آزمایش شوند.

## نکات مربوط به پروتکل‌ها
- در این نسخه فقط لینک‌های VLESS و Trojan از طریق مبدل فعلی قابل راه‌اندازی هستند؛ VMess، Shadowsocks، SOCKS و Hysteria2 هنوز مسیر اتصال کامل ندارند و نباید به‌عنوان سرور قابل اتصال انتخاب شوند.
- پشتیبانی VLESS/Trojan به نوع انتقال و فیلدهای داخل لینک وابسته است؛ همهٔ ترکیب‌های Xray یا همهٔ لینک‌های ناشناس تضمین نشده‌اند.
- Tor/obfs4 مسیر جداگانه‌ای دارد. به‌دلیل TCP-only بودن مسیر SOCKS این حالت، UDP از تونل مسدود می‌شود.
- کانفیگ‌ها و پل‌های عمومی از منابع ثالث دریافت می‌شوند؛ آنلاین بودن، امنیت یا قابل‌اتصال بودن آن‌ها تضمین‌شده نیست.
- اطلاعات محرمانه کانفیگ‌ها را با دیگران به اشتراک نگذارید.

## دریافت APK آزمایشی
آخرین APK آزمایشی arm64 را از بخش Artifacts گردش‌کار GitHub Actions دریافت کنید:
https://github.com/m09127252638-max/raha-vpn/actions

فایل artifact با نام `H-MAGHSODI-arm64-debug` منتشر شده و شامل `app-arm64-v8a-debug.apk` است.

## ساخت
پروژه با JDK 17، Android SDK platform 35 و Go 1.27.3 تنظیم شده است. گردش‌کار GitHub Actions تست‌های واحد و APK آزمایشی arm64 را می‌سازد.
