# ATENAMONTAZER

اپلیکیشن اندروید ATENAMONTAZER با رابط کاربری فارسی و تم تیره.

## وضعیت فعلی
- پوسته اولیه Android با Jetpack Compose
- رابط فارسی و تم سرمه‌ای/طلایی
- فهرست سرورها و افزودن لینک کانفیگ‌های VMess، VLESS، Trojan، Shadowsocks و WireGuard
- ذخیره‌سازی لینک‌های کانفیگ با رمزگذاری AES-GCM و کلید Android Keystore
- بررسی دسترسی DNS-over-HTTPS از طریق Cloudflare و Google
- وابستگی موتور sing-box (libbox) برای پیاده‌سازی تونل VPN در حال اضافه‌شدن است.

## نکته مهم
در نسخه فعلی هنوز تونل VPN فعال نشده است؛ دکمه اتصال تا تکمیل سرویس Android VPN و اتصال امن libbox غیرفعال می‌ماند. افزودن کانفیگ به معنی برقرار شدن اتصال نیست. بررسی DNS فقط دسترسی DNS را آزمایش می‌کند و جایگزین VPN نیست.

## ساخت پروژه
پروژه را با Android Studio سازگار با Android Gradle Plugin 8.7.3 باز کنید و Gradle Sync را اجرا کنید.
